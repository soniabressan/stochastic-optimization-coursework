# Stochastic optimization – coursework

Two assignments for the course *Optimization and simulation under uncertainty* (MSc Mathematical Engineering, Politecnico di Torino, 2026).
Joint work by Sonia Bressan and Alessia Gambuzza. Reports are in Italian.

| Folder | Topic | Tools |
| --- | --- | --- |
| [01-newsvendor-monte-carlo](01-newsvendor-monte-carlo) | Newsvendor model: how estimation error on demand and salvage value reduces profit, measured by Monte Carlo simulation | MATLAB |
| [02-two-stage-stochastic-programming](02-two-stage-stochastic-programming) | Two-stage stochastic program for an assembly-to-order production problem: scenario stability, VSS/EVPI, robustness to a biased demand model | Python, NumPy, Gurobi |
